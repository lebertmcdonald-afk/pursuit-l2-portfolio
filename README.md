# Pursuit L2 Portfolio

Four projects built across four cycles, covering full-stack development, AI agent design, and design systems work.

## Projects

### 1. [PA Status Relay](https://github.com/lebertmcdonald-afk/capstone-project)
Prior-authorization status tracker for oncology care coordinators, with a full audit trail and workflow validation. Built with Node.js, Express, SQLite.

### 2. [OpenLine](https://github.com/lebertmcdonald-afk/Openline-Agent)
An AI agent that researches sales prospects and drafts personalized cold outreach, then verifies its own draft before handing it to a human. Built with Python, Strands Agents, Claude Sonnet 5.

### 3. [Care Compass](https://github.com/lebertmcdonald-afk/CareCompass)
A React monorepo with two connected tools: an internal coordinator dashboard and a public agency finder for families seeking home health care. Built with TypeScript, React.

### 4. [Morning Briefing Agent](https://github.com/lebertmcdonald-afk/Morning-briefing-agent)
An agent that reads Gmail, Calendar, and Slack each morning and returns one clean, organized summary. Built with Python, Strands Agents.
