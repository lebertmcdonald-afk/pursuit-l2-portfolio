# Pursuit L2 Portfolio

Four projects built across four cycles, covering full-stack development, AI agent design, and design systems work.

## Projects

### 1. [Notion Notes (Pagepad)](https://github.com/lebertmcdonald-afk/frontend-pagepad)
A full-stack note-taking app for solo users who want structure without Notion's setup tax. Built with React, Vite, Node, Hono, SQLite. [Live app](https://notion-notes-cyan.vercel.app)

### 2. [Care Compass](https://github.com/lebertmcdonald-afk/CareCompass)
A React monorepo with two connected tools: an internal coordinator dashboard and a public agency finder, built around a real "care desert" data insight computed from CMS and Census data. Built with TypeScript, React.

### 3. [OpenLine](https://github.com/lebertmcdonald-afk/Openline-Agent)
An AI agent that researches sales prospects and drafts personalized cold outreach, then verifies its own draft before handing it to a human. Built with Python, Strands Agents, Claude Sonnet 5.

### 4. [PA Status Relay](https://github.com/lebertmcdonald-afk/capstone-project)
Prior-authorization status tracker for oncology care coordinators, with a full audit trail and workflow validation. Capstone build, in progress. Built with Node.js, Express, SQLite.
